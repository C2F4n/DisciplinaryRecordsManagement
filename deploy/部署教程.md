# 违纪统计系统部署教程

适用于在另一台 Windows 电脑上运行本部署包。前提：已安装 Java 21 或更高版本、MySQL 8。
配置项以包内的 `.env.example` 为唯一模板，本文只说明「必须改哪几个」。

## 0. 部署包里有什么

| 文件 | 作用 |
| --- | --- |
| `DisciplinaryRecordsManagement-*.jar` | 程序本体（内含前端页面与默认配置） |
| `.https\server.p12`、`.https\localhost.cer` | 本机 HTTPS 证书与私钥（不要外传） |
| `启动系统.cmd` | 启动入口，会先切到本目录再运行 JAR |
| `重置管理员密码.ps1` | 管理员密码忘了时用：生成 bcrypt 哈希并给出 SQL |
| `.env` | 本机实际启动配置（**明文口令，不要外传**） |
| `.env.example` | 配置模板，列出全部可用配置项及注释 |
| `包信息.txt` | 构建时间、JAR 的 SHA-256、运行环境与迁移版本，用于核对交付物 |
| `部署教程.md`、`SMTP配置页说明.md` | 本文与邮件设置说明 |

收到包后建议先核对一次，确认文件在拷贝过程中没被替换或损坏：

```powershell
Get-FileHash .\DisciplinaryRecordsManagement-*.jar -Algorithm SHA256
```

把结果与 `包信息.txt` 里的 `SHA-256` 比对，不一致就不要启动，重新拷贝。另外 `.env` 和 `.https` 是每份交付单独生成的，**不要跨包混用**（keystore 口令写在各自的 `.env` 里）。

## 1. 创建数据库和程序账号

在部署目录打开 PowerShell，用 MySQL 管理账号登录：

```powershell
mysql.exe -u root -p
```

在 `mysql>` 下执行（把示例密码换成你要用的密码）：

```sql
CREATE DATABASE disciplinary_records
  CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;

CREATE USER 'discipline_app'@'127.0.0.1'
  IDENTIFIED BY '换成你的数据库密码';

GRANT ALL PRIVILEGES ON disciplinary_records.*
  TO 'discipline_app'@'127.0.0.1';
```

库名、账号可以自定义，但必须与第 2 步的 `.env` 保持一致。已有可用的空库时，只需为该账号授权。

## 2. 填写 .env

用记事本打开 `.env`，**通常只需要填 3 处**：

```dotenv
DB_PASSWORD=换成第 1 步设置的数据库密码
APP_ADMIN_USERNAME=admin
APP_ADMIN_PASSWORD=换成你的网页管理员初始密码
```

用 `打包.ps1` 生成的交付包里，`server.ssl.key-store-password` 已由脚本按新证书自动填好，不用再管；手工拼包时才需要自己填。

| 键 | 是否必填 | 说明 |
| --- | --- | --- |
| `DB_URL` | 一般不改 | MySQL 地址与库名，默认 `127.0.0.1:3306/disciplinary_records`。**末尾的 `connectionTimeZone` 不要删**，否则日期会随时区偏移 |
| `DB_USER` / `DB_PASSWORD` | **必填** | 第 1 步创建的程序账号与其密码 |
| `APP_ADMIN_USERNAME` | 建议改 | 网页管理员登录名：小写字母开头，4–48 位 |
| `APP_ADMIN_PASSWORD` | **必填（空库）** | 网页管理员初始密码。**留空 = 一个管理员都不建，登录页会一直提示「用户名或密码不正确」** |
| `server.ssl.*`、`SESSION_COOKIE_SECURE` | 保持原样 | 本机 HTTPS 证书。删掉 SSL 就必须同时把 Cookie 改成 `false` |
| `APP_PORT` / `BIND_ADDRESS` | 留空即可 | 默认 `18643`、仅本机访问。要开放给同网段时改为 `0.0.0.0` |
| 其余 `APP_*`、`SMTP_*` | 留空 | 使用程序默认值，详见 `.env.example` 注释 |

**管理员密码规则**：6–18 位，至少包含一个英文字母和一个数字，只允许英文字母、数字、`_`、`@`（区分大小写）。写成六位纯数字会被当作 24 小时有效的临时密码，且仅允许本机监听。

**写 `.env` 的两条硬规矩**：值一律用 ASCII、不加引号；中文只能写在 `#` 注释里（值会按 ISO-8859-1 读取，中文值会乱码）。

`APP_ADMIN_*` 只在「库中还没有核心管理员」时生效，之后改这两行没有作用；管理员密码已存在 MySQL 里，请登录后在页面修改。所以首次登录后**务必立刻改掉初始密码**——它是以明文躺在 `.env` 里的。

⚠️ **最容易踩的坑**：`.env` 里 `APP_ADMIN_PASSWORD` 是空的（模板默认就是空的），直接启动 → 确实能起来、也能打开登录页，但**数据库里没有任何管理员**，任何账号都登不进去。填好密码后必须**重启**才会建号。

## 3. 启动并登录

1. 双击 `启动系统.cmd`，保持窗口打开。
2. 首次连接空库时自动建表（Flyway 迁移，共 17 个版本）并写入基础配置、创建网页管理员。
3. 浏览器打开 <https://localhost:18643>。用的是自签证书，提示「不安全」属于正常，选择继续访问即可。**必须用 https**，用 http 会得到 400。
4. 需要学生注册验证码或违纪提醒邮件时，按 [SMTP配置页说明](./SMTP配置页说明.md) 填写发件邮箱。

停止服务：在启动窗口按 `Ctrl+C`。

## 4. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 浏览器打不开，或返回 400 | 用了 `http://` 访问 TLS 端口 | 改成 `https://localhost:18643` |
| 登录成功后立刻跳回登录页 | `server.ssl.enabled=false` 但 `SESSION_COOKIE_SECURE=true` | 两者必须一致 |
| 启动即退出，日志含「密码须为 6–18 个字符」 | 空库首启时 `APP_ADMIN_PASSWORD` 不合规 | 按上面的规则改该值后重启 |
| 启动报找不到 key-store | 不是用 `启动系统.cmd` 启动，工作目录不是部署目录 | 用 `启动系统.cmd`，或先 `cd` 到该目录 |
| 启动报数据库连接失败 | `DB_*` 与 MySQL 里的账号/库名不一致，或 MySQL 未启动 | 核对 `.env`、检查 MySQL80 服务 |
| **登录一直提示「用户名或密码不正确，或账号已失效」** | ① `.env` 里 `APP_ADMIN_PASSWORD` 为空 → 库中没有任何管理员；② 库是从旧机器导入的，管理员已存在，`.env` 这两行被忽略 | 先跑文末「查管理员」SQL：0 行按 ① 处理（填密码 + 重启）；有行按 ② 处理（用旧密码，或运行 `重置管理员密码.ps1`） |

## 5. 密码进不去怎么办

先确认库里到底有没有管理员。用 MySQL 管理账号执行：

```sql
USE disciplinary_records;
SELECT id, username, core_admin_slot FROM app_user WHERE core_admin_slot = 1;
```

**查到 0 行**（库是空的、没建号）：把 `.env` 的 `APP_ADMIN_USERNAME`、`APP_ADMIN_PASSWORD` 填好，**重启程序**，启动时会自动建号。密码规则见第 2 节。

**查到 1 行**（管理员已存在，通常是导入了旧库）：`.env` 里那两行不会再生效，只能用数据库里原有的密码。如果旧密码也忘了，运行包内的 `重置管理员密码.ps1`：

```powershell
.\重置管理员密码.ps1 -Username admin -Password Adm1n_2026Xyz
```

它会用程序自带的 BCrypt 算法算出哈希，并打印一条 `UPDATE` 语句；把那条 SQL 在 MySQL 里执行即可，无需重启。脚本需要 JDK（要有 `javac`）。

## 6. 配置与数据保存在哪里

| 位置 | 用途 |
| --- | --- |
| `.env` | 启动配置：数据库连接、管理员初始化、端口、证书位置 |
| JAR 内部 `application.properties` | 随包提供的默认配置（`.env` 覆盖它） |
| MySQL `disciplinary_records` | 全部业务数据，以及后台保存的 SMTP、导出模板、检查项目等设置 |
| `.https\` | HTTPS 证书与私钥 |
| `.smtp-settings.key` | 首次保存 SMTP 授权码时自动生成，用于解密授权码 |
| `logs\disciplinary.log` | 运行日志，按 10MB 滚动，保留 14 天 |

## 7. 迁移到另一台电脑

1. 停掉服务（`Ctrl+C`）。
2. 一起拷走：JAR、`.env`、`.https\`、`.smtp-settings.key`、`启动系统.cmd`。
3. 数据库用 `mysqldump` 导出再导入；导入的是空库时，`APP_ADMIN_*` 会重新建号。
4. 新机器的 MySQL 账号密码若与原来不同，改 `.env` 的 `DB_PASSWORD` 后重启。
