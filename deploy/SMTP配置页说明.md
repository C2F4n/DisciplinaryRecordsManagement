# SMTP 配置页说明

核心管理员登录后，打开「系统管理 → SMTP 配置」。

第一次解锁使用初始配置密码 `a018779`。改过密码后用新密码。解锁有效期 10 分钟，离开页面或点击「锁定配置」后，再查看配置需重新解锁。

> **这个初始密码是程序内置的，所有安装相同**（由数据库迁移写入固定的 bcrypt 哈希）。第一次解锁后请立即按文末「修改配置密码」改掉，否则知道这个值的人都能进入 SMTP 配置页。

## 发件服务器

请将下面的示例替换成邮箱服务商给你的 SMTP 参数。

| 页面字段 | 填写什么 | 作用 |
| --- | --- | --- |
| **启用违纪邮件通知** | 需要自动发送违纪邮件时勾选 | 控制新登记的违纪是否额外发邮件。注册验证码使用下方同一套发件设置 |
| **SMTP 服务器** | 服务商提供的服务器地址，如 `smtp.example.com` | 程序连接这个服务器发送邮件 |
| **端口** | 服务商指定的 SMTP 端口 | 程序通过该端口连接发件服务器。端口与「连接加密」配套填写 |
| **连接加密** | 按服务商要求选择 STARTTLS、SSL/TLS 或无加密 | STARTTLS 常配 `587`，SSL/TLS 常配 `465`。只有服务商明确提供无加密中继时才选「无加密」 |
| **发件邮箱** | 有权用来发信的完整邮箱地址 | 显示在收件人看到的「发件人」一栏。一般与 SMTP 登录账号相同 |
| **使用 SMTP 身份认证** | 普通邮箱通常勾选 | 勾选后，程序用下面的账号和授权码登录 SMTP 服务 |
| **SMTP 登录账号** | 邮箱服务商指定的登录名，通常是完整邮箱地址 | SMTP 服务器凭这个账号识别发件人 |
| **SMTP 授权码** | 邮箱服务商提供的 SMTP 授权码或应用专用密码 | 配合 SMTP 登录账号完成认证。显示「已配置」时，留空保存会保留原授权码 |

### 保存和核对状态

1. 点击「保存 SMTP 配置」，停止并重启程序。
2. 重新打开配置页。**注册验证码已配置**表示程序已加载 SMTP 设置。可以通过学生注册页发送一封验证码来确认收件。
3. **违纪邮件已启用**表示违纪邮件开关与 SMTP 配置均已生效。页面出现**已保存的变更待重启生效**时，重启后再测试。

后台保存的 SMTP 参数在 MySQL 中。授权码加密保存，程序使用自动生成的 `.smtp-settings.key` 解密。换电脑后如果需要重新设置发件凭据，可以直接在页面填写授权码并重启。

## 修改配置密码

| 页面字段 | 填写什么 |
| --- | --- |
| **当前配置密码** | 当前用于解锁 SMTP 配置页的密码 |
| **新配置密码** | 6–18 位字符，至少包含一个英文字母和一个数字，允许英文字母、数字、`_` 和 `@` |
| **确认新配置密码** | 再输入一次新配置密码 |

点击「修改配置密码」后，页面会重新锁定。用新密码解锁即可。
